# ccf-reader quality gate

The output passes only if:

1. It directly addresses the user's requested artifact.
2. It is adapted to CCF-A conference/journal norms.
3. It does not invent citations, results, or venue rules.
4. It contains at least one evidence/assumption section.
5. It identifies likely reviewer risk.
6. It gives concrete next actions.

Automatic failure:

- Generic academic advice without task-specific content.
- Strong claims without evidence.
- Fabricated numbers or references.
- Missing venue/paper-type adaptation when the user provided a target venue.
