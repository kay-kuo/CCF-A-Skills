# Venue adaptation notes for ccf-presentation

Use this as a heuristic guide only. Always defer to the current official author instructions for the target venue.

## ML general venues

Prioritize method novelty, baselines, ablation, theory/assumptions, reproducibility, limitations, and checklist readiness.

## CV venues

Prioritize clear visual pipeline, benchmark comparisons, visual case studies, ablations, robustness, and efficiency.

## NLP venues

Prioritize task definition, data construction, contamination control, human evaluation, linguistic/reasoning analysis, and error analysis.

## Data mining / IR / Web venues

Prioritize real-world problem scale, strong baselines, offline/online evaluation, efficiency, user/system implications, and dataset validity.

## Systems / security / software engineering / PL

Prioritize threat or workload model, system design choices, measurement methodology, artifact availability, and real-world deployment constraints.

## Medical AI / imaging

Prioritize data provenance, external validation, leakage prevention, clinical relevance, statistical reporting, ethics/privacy, and safety limitations.

## Journal extension

Prioritize completeness, additional experiments, deeper analysis, improved related work, clear extension beyond earlier conference versions, and traceable revisions.
