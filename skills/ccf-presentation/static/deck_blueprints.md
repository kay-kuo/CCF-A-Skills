# ccf-presentation deck blueprints

## 10-minute conference oral

1. Title and one-sentence takeaway.
2. Problem and why it matters.
3. Technical challenge.
4. Core insight.
5. Method overview.
6. Main result.
7. Ablation/analysis.
8. Case study or qualitative result.
9. Limitation.
10. Takeaway.

## 30-60 minute journal club

1. Background.
2. Problem setting.
3. Related work map.
4. Method details.
5. Experiment protocol.
6. Main results.
7. Ablation and analysis.
8. Strengths.
9. Weaknesses/reviewer questions.
10. Ideas for our project.

## Internal defense

1. What is the submission claim?
2. What evidence supports it?
3. What will reviewers attack?
4. Which fix is mandatory before submission?
5. Which fix is optional?
