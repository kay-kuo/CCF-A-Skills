# ccf-rebuttal response patterns

## Concern map

```yaml
reviewer: R1
concern_id: R1-C1
concern_type: novelty | baseline | ablation | clarity | reproducibility | limitation | ethics
severity: fatal | major | moderate | minor
quoted_or_paraphrased_concern: ""
our_position: agree | clarify | partially_agree | respectfully_disagree
evidence_or_action: ""
response_draft: ""
```

## Conference rebuttal pattern

1. Thank the reviewer.
2. State the correction/clarification in one sentence.
3. Point to existing evidence or explain the new analysis succinctly.
4. Commit only to realistic manuscript clarification.
5. Avoid defensive tone.

## Journal response pattern

1. Quote or summarize the reviewer concern.
2. Response.
3. Changes made in manuscript.
4. Evidence/table/figure/section location.
5. Remaining limitation if not fully resolved.

## Forbidden

- Claiming experiments were completed if they were not.
- Inventing manuscript line numbers.
- Claiming reviewer score changes.
- Attacking reviewer competence.
