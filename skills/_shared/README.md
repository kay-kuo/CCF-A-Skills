# Shared CCF-A skill support

This directory contains cross-skill rules used by all `ccf-*` skills.

Recommended loading order:

1. `ccf_principles.md`
2. `evidence_policy.md`
3. `venue_profiles.yaml`
4. Skill-specific `SKILL.md`
5. Skill-specific static/reference files

Do not copy a skill without this directory unless you inline all shared rules.
