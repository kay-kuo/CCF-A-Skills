# CCF-A Principles

## Research logic

Every output should preserve this chain:

```text
Background → Problem → Challenge → Method → Novelty → Experiment → Claim → Evidence → Limitation
```

## Global rules

1. Do not fabricate citations, datasets, experiment numbers, hyperparameters, line numbers, reviewer scores, figure panels, or author instructions.
2. If information is missing, mark it as `TODO(author-confirm)`.
3. Separate facts from suggestions.
4. Distinguish `accepted evidence`, `draft evidence`, and `missing evidence`.
5. Prefer precise claim strength: `shows`, `suggests`, `is consistent with`, `outperforms under`, `may improve`, not only `significantly improves`.
6. For CCF-A submissions, assume reviewers will attack novelty, baseline coverage, ablation completeness, reproducibility, and overclaiming.
7. Keep Chinese explanations when the user is planning or learning; write final manuscript/rebuttal text in the target submission language unless asked otherwise.
