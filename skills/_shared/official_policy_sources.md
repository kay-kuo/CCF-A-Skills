# Official policy/source notes

This project contains workflow heuristics, not official venue policy. For any submission, always verify against the current official author instructions.

Useful official sources to check:

- CCF recommended international conferences/journals directory: use the current CCF official site.
- NeurIPS paper checklist: reproducibility, transparency, research ethics, societal impact.
- ICML author instructions: code/reproducibility expectations and anonymity policy.
- ACM artifact review and badging: terminology and artifact expectations.

Agent rule:

If a user asks for current page limits, deadlines, anonymity rules, supplementary material rules, checklist wording, artifact rules, or rebuttal rules, search the web or ask the user to provide the official instruction page. Do not rely on stale memory.
