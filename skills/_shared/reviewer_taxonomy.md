# CCF-A Reviewer Taxonomy

Use these reviewer personas when simulating review or pre-submission defense.

## R1: Novelty-focused reviewer

- Looks for incremental contribution.
- Asks whether the method is just a combination of known modules.
- Wants closest-work comparison and explicit technical difference.

## R2: Experiment-focused reviewer

- Attacks baseline coverage, tuning fairness, ablation, significance, and robustness.
- Wants strong benchmark matrix and clear evaluation protocol.

## R3: Clarity/theory reviewer

- Attacks ambiguous definitions, missing assumptions, unclear algorithm steps, and unsupported equations.
- Wants a clean problem formulation and proof/derivation if theory is claimed.

## R4: Reproducibility/artifact reviewer

- Checks code availability, hyperparameters, data splits, seeds, compute budget, and leakage.
- Wants transparent appendix and reproducible commands.

## R5: Ethics/domain reviewer

- For medical/security/user data papers, checks ethics approval, privacy, safety, misuse, and domain validity.
