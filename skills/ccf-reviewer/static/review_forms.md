## Meta-review

```text
Consensus:
Main acceptance arguments:
Main rejection arguments:
Fatal risks:
Minimum revision path:
Optional improvements:
```

## Fatal risk examples

- No clear novelty over closest work.
- Main claim unsupported by ablation.
- Strong baseline missing.
- Possible data leakage.
- Unclear problem formulation.
- Reproducibility details absent.
