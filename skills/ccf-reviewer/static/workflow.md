# ccf-reviewer workflow

## Primary workflow

```text
read draft → assign reviewer personas → write reviews → meta-review → action plan
```

## Step template

1. Identify the target venue family and paper type.
2. Identify what evidence is available.
3. Produce the requested output in a CCF-A reviewer-aware format.
4. Build or update claim-evidence mapping.
5. Add reviewer-risk notes.
6. Run the rubric and revise once.

## Output discipline

- Use concise technical language.
- Separate manuscript-ready text from planning notes.
- Use `TODO(author-confirm)` for missing facts.
- Avoid generic advice unless it is attached to a concrete fix.
