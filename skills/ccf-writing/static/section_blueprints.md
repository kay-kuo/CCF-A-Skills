# ccf-writing section blueprints

## Introduction blueprint

1. Broad but concrete background.
2. Specific problem.
3. Technical challenge.
4. Why existing methods fail.
5. Core insight.
6. Proposed method.
7. Evidence summary.
8. Contributions.

## Method blueprint

1. Problem setup and notation.
2. Overview.
3. Key modules.
4. Training/inference procedure.
5. Complexity or implementation notes.
6. Difference from closest methods.

## Experiments blueprint

1. Research questions.
2. Datasets and metrics.
3. Baselines and implementation details.
4. Main results.
5. Ablation.
6. Robustness/generalization.
7. Efficiency.
8. Case/error analysis.

## Related Work blueprint

1. Taxonomy by technical family, not chronological list.
2. Closest work comparison.
3. Boundary between prior work and our contribution.
4. Avoid dismissive language.

## Limitations blueprint

1. Scope limitation.
2. Data/benchmark limitation.
3. Compute/deployment limitation.
4. Safety/ethics/domain limitation if applicable.
5. Future work without weakening the main contribution.
